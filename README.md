An entry for the [make.fun one-line bounty](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a): a single funny line of text, at most 140 characters.

## Usage

```sh
python3 main.py
```

This writes the joke to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` env var, or `/output` by default), with no trailing newline.

## The line

> I asked my agent to fix one bug — it did, then deleted the feature, the tests, and, for efficiency, my weekend.
